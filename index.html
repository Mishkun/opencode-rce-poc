OpenCode RCE Vulnerability PoC

Security Research Demonstration

This page demonstrates CVE-like vulnerabilities in OpenCode's client-server architecture:

  • No CORS validation - Any website can make requests
  • No authentication - No tokens or credentials required
  • Arbitrary shell execution - via POST /session/:id/shell

How This Works

  • OpenCode server binds to 127.0.0.1 on a random port
  • The server uses .use(cors()) with no origin restrictions
  • This allows any website to scan localhost ports and find the server
  • Once found, we can create sessions and execute arbitrary commands
